# Page introuvable (`landing/404.html`)

Socle : [../SPEC.md](../SPEC.md).

**Objectif** : ne jamais laisser un visiteur dans une impasse. Le ramener vers l'accueil, les
pages principales ou WhatsApp, et aiguiller ceux qui cherchaient en fait à se connecter.

Servie par Nginx avec le statut HTTP 404 (`error_page 404 /404.html;`, SPEC §10.5) à **n'importe
quelle adresse** : tous les chemins (CSS, JS, images, polices, liens) sont **absolus depuis la
racine** (`/assets/...`, `/tarifs`).

## Balises

| Balise | Valeur |
|---|---|
| `title` | Page introuvable \| School Manager |
| `meta description` | La page demandée n'existe pas ou a été déplacée. |
| `robots` | `<meta name="robots" content="noindex">` |
| `canonical`, Open Graph | aucun |
| WhatsApp de la page | W8 |
| `aria-current` | aucun |

## Gabarit

0. En-tête commun · 1. Message · 2. Pied de page commun. Fond papier.

## 1. Message (`main`, conteneur `--narrow`, `padding-block: clamp(4rem, 12vw, 8rem)`)

| Élément | Texte |
|---|---|
| Icône | Icône de l'application `/assets/brand/icone-72.png` affichée à 56 px, `alt=""` |
| Surtitre | Erreur 404 |
| `h1` | Cette page n'existe pas, ou plus. |
| Paragraphe | Le lien est peut-être incomplet, ou la page a été déplacée. |
| `.btn-green` | Retour à l'accueil → `/` |
| `.btn-outline` | icône WhatsApp + « Nous écrire sur WhatsApp » → W8 |

Puis `h2` (20 px) « Vous cherchiez peut-être : » et liste de liens `.more` :
Fonctionnalités (`/fonctionnalites`) · Tarifs (`/tarifs`) · Parents (`/parents`) · Sécurité
(`/securite`).

Encadré `.notice` :
« **Vous voulez vous connecter ?** Enseignants, parents et élèves : utilisez l'application
School Manager sur votre téléphone. Direction et secrétariat : » + lien « se connecter à la
plateforme web » → `/login` + « . »
